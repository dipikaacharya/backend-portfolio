# Portfolio Backend (Express.js)

This is the backend service for my personal portfolio website, built using **Node.js** and **Express.js**. It handles API requests, contact form submissions, and serves as the core server layer for my portfolio system.

---

## 🚀 Features

- RESTful API built with Express.js
- Contact form handling (email/message processing)
- CORS-enabled for frontend integration
- Environment-based configuration
- Lightweight and scalable structure
- Ready for deployment (Vercel)

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- dotenv
- cors

---

## ⚙️ Installation & Setup

```bash
git clone https://github.com/your-username/your-backend-repo.git
cd your-backend-repo
npm install
npm run dev


```
